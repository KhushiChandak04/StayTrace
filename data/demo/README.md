# Demo fixtures

The JPG files in this directory are **controlled synthetic test fixtures**, not photographs of a real room. They exist so the comparison engine and automated tests have deterministic inputs.

For a competition-quality demonstration, use the application's **Upload photos** or **Camera capture** modes with your own real move-in and move-out photographs. The application supports ordinary JPG, JPEG, PNG and WebP images.

Recommended real-photo capture practice:

1. Use the same room viewpoints at move-in and move-out.
2. Keep the camera orientation and distance as similar as practical.
3. Capture overview shots plus close-ups of existing damage.
4. Rename paired files consistently, for example `01_desk.jpg` in both inspections.
5. Keep the original images; StayTrace stores SHA-256 hashes for evidence integrity.
